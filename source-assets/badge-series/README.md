# Portfolio badge series

Sixteen certification cards share a deterministic 1630 × 965 composition. All headings use Nimbus Sans Bold at an optical size keyed to each title's length; short titles such as Dante are larger. All subtitles use Nimbus Sans Regular at 65 px. Type has a restrained solid off-white finish rather than faux metallic emboss. Text is converted to vector outlines, so the result never depends on installed browser fonts. One-line and two-line titles stay within a fixed title zone. A shared header slot, emblem slot, frame, owner baseline, counter and metadata locations define the full series.

`catalog.json` preserves card labels, years, dates, identifiers and source-emblem viewports. `extracted-palettes.json` records color samples and certificate source paths. The multicolor Oracle background additionally uses source border samples: RGB(190,66,71), (106,59,50), (199,132,105), (207,199,181), (117,126,114), (35,70,79). The seven Cisco cards each have a distinct illustration keyed to their certification subject. The two Fortinet cards use distinct scenes for FortiGate operations and next-generation firewall protection. Card 16 replaces Wanderer with the user supplied Microsoft Security Operations Analyst Associate image and uses a blue-only background palette. Its stored PDF is an image-only conversion of the supplied JPEG, not an issuer PDF.

The `.webp` illustration backgrounds are generated raster artwork. They contain no typography, logos or issuer seals. Actual issuer emblems come from the retained original cards; header logo vectors come from existing portfolio assets. The Nimbus Sans fonts and their license are included to reproduce layout.

Rebuild the Microsoft image assets with `python tools/import-microsoft-cert.py`, then run `python tools/build-badge-series.py` and `node tools/render-badge-series.cjs`. Generated intermediate badge SVGs are ignored. The production cards are flattened responsive WebP files at 640, 1120 and 1630 pixels, with lazy loading in the existing grid. On Microsoft hover, a centered certificate appears over its blurred background in the same 1000 × 1010 format as the other certificate previews. The card has no PDF arrow or link.

# Portfolio - Sofiane Ghazal

Portfolio full code en HTML/CSS/JS, optimise pour GitHub Pages.

## Structure
- `index.html` : contenu principal
- `styles.css` : styles et mise en page
- `script.js` : animations simples (reveal)
- `assets/` : place pour images ou CV PDF

## A personnaliser rapidement
1. Remplacer les cartes **Projet de cours #1/2/3** dans `index.html`.
2. Ajouter un CV PDF dans `assets/` puis creer un bouton de telechargement.
3. Modifier les couleurs et textes si besoin dans `styles.css`.

## Publication GitHub Pages
1. Creer un repo GitHub (ex: `portfolio-sofiane`).
2. `git init`, `git add .`, `git commit -m "Initial portfolio"`.
3. `git branch -M main`, `git remote add origin https://github.com/Sosocz/TON-REPO.git`.
4. `git push -u origin main`.
5. GitHub > Settings > Pages > Deploy from Branch `main` / root.
